Les mesures de dispersion

Module de mathématiques MDM4U

1. À quoi servent les mesures de dispersion?

Les mesures de dispersion servent à comprendre à quel point les données d'un ensemble sont réparties ou éloignées les unes des autres. Elles nous permettent de voir si les valeurs sont proches ou si elles sont très différentes.

Par exemple, deux classes peuvent avoir la même moyenne à un examen, mais des résultats très différents. Dans une classe, les notes peuvent être proches de la moyenne, tandis que dans l'autre, elles peuvent être très éloignées. Les mesures de dispersion permettent de comparer ces situations.

2. L'étendue

L'étendue est la différence entre la plus grande valeur et la plus petite valeur d'un ensemble de données. Elle donne une idée de l'écart total entre les deux extrêmes.

Formule :
Étendue = valeur maximale − valeur minimale

Exemple :

Voici les notes suivantes : 5, 7, 8, 10, 12.

La valeur maximale est 12 et la valeur minimale est 5.

Étendue = 12 − 5 = 7

L'étendue est donc de 7. Plus l'étendue est grande, plus l'écart entre les valeurs extrêmes est important.

3. Les quartiles

Les quartiles divisent un ensemble de données ordonnées en quatre parties. Ils permettent de comprendre comment les données sont réparties.

  • Premier quartile (Q1) : environ 25 % des données sont inférieures ou égales à cette valeur.
  • Deuxième quartile (Q2) : c'est la médiane. Environ 50 % des données se trouvent de chaque côté.
  • Troisième quartile (Q3) : environ 75 % des données sont inférieures ou égales à cette valeur.

Pour trouver les quartiles, il faut d'abord classer les données en ordre croissant. Ensuite, on trouve la médiane et les médianes des deux moitiés de la distribution, selon la méthode utilisée dans le cours.

Exemple :

Pour les données 2, 4, 6, 8, 10, 12, 14, on obtient :

  • Q1 = 4
  • Q2 = 8
  • Q3 = 12

Les quartiles permettent donc de repérer où se situent les données dans un ensemble. Les résultats peuvent varier selon la convention de calcul utilisée, particulièrement pour les petits ensembles de données.

4. L'écart interquartile

L'écart interquartile mesure la dispersion des 50 % de données qui se trouvent au centre de l'ensemble. Il correspond à la différence entre le troisième quartile et le premier quartile.

Formule :
Écart interquartile = Q3 − Q1

Exemple :

Si Q1 = 4 et Q3 = 12 :

Écart interquartile = 12 − 4 = 8

L'écart interquartile est donc de 8. Un écart interquartile plus petit signifie que les données centrales sont plus regroupées. Contrairement à l'étendue, il est peu influencé par les valeurs extrêmes.

5. L'écart type

L'écart type mesure à quel point les valeurs d'un ensemble sont éloignées de leur moyenne. Il tient compte de toutes les données.

Un écart type faible signifie que les valeurs sont généralement proches de la moyenne. Un écart type élevé signifie que les valeurs sont davantage dispersées.

L'écart type est exprimé dans la même unité que les données. Par exemple, si les données représentent des notes sur 100, l'écart type est aussi exprimé en points.

6. Comment calculer l'écart type?

Pour calculer l'écart type d'une population, on peut suivre les étapes suivantes :

  1. Calculer la moyenne de toutes les données.
  2. Soustraire la moyenne de chaque valeur.
  3. Élever chaque différence au carré.
  4. Calculer la moyenne de toutes les différences au carré.
  5. Calculer la racine carrée du résultat obtenu.
Formule de l'écart type d'une population :

σ = √[Σ(x − μ)² / N]

Dans cette formule :

  • σ représente l'écart type.
  • x représente chaque valeur de l'ensemble.
  • μ représente la moyenne.
  • N représente le nombre total de valeurs.
  • Σ signifie qu'il faut additionner les résultats.

Exemple :

Prenons les données suivantes : 2, 4 et 6.

Étape 1 : Calculer la moyenne.

Moyenne = (2 + 4 + 6) / 3 = 4

Étape 2 : Soustraire la moyenne à chaque valeur, puis élever les différences au carré.

  • (2 − 4)² = 4
  • (4 − 4)² = 0
  • (6 − 4)² = 4

Étape 3 : Calculer la moyenne des différences au carré.

(4 + 0 + 4) / 3 = 8 / 3 ≈ 2,67

Étape 4 : Calculer la racine carrée.

σ = √(2,67) ≈ 1,63

L'écart type de cette population est donc d'environ 1,63. Cela indique à quel point les valeurs sont dispersées autour de leur moyenne, qui est de 4.

Attention : pour un échantillon, la formule utilise généralement n − 1 au dénominateur au lieu de N. Il faut utiliser la formule demandée dans votre cours.
