Module 2.2 : Mesures de tendance centrale

Résumé des notes de cours et des explications du module 2.2 sur les mesures de tendance centrale.

1. Moyenne arithmétique

Définition : C'est la somme de toutes les valeurs divisée par le nombre total de données. Elle tient compte de chaque valeur mais est très sensible aux valeurs aberrantes.

Formule :

x̄ = Σ xi n

Exemple : Pour les notes 70, 80 et 90, la moyenne est :

(70 + 80 + 90) ÷ 3 = 80

2. Moyenne pondérée

Définition : Utilisée lorsque certaines valeurs ont plus d'importance (poids ou fréquence) que d'autres (ex. notes de cours avec examens et travaux).

Formule :

x̄ = Σ (f × x) Σ f

Exemple : Une note de 80% comptant pour 70% et un examen de 90% comptant pour 30% donne :

(80 × 0,7) + (90 × 0,3) = 56 + 27 = 83%

3. Moyenne de données groupées

Principe : Quand les données sont données par intervalles (ex. 10-20), on ne connaît pas les valeurs exactes. On utilise la même méthode que la moyenne pondérée en prenant le point milieu de chaque intervalle.

Formule :

Moyenne estimée = Σ (m × f) Σ f

Où : m = point milieu de l'intervalle et f = fréquence.

Étapes : Trouver le point milieu de chaque classe, multiplier par la fréquence, sommer le tout et diviser par la somme des fréquences.

4. Médiane

Définition : C'est la valeur centrale qui sépare une série de données ordonnées en deux parties égales. Elle est idéale s'il y a des valeurs aberrantes.

Comment la trouver :

  • Classer les données du plus petit au plus grand.
  • Si le nombre de valeurs (n) est impair, la position est :
Position = n + 1 2
  • Si n est pair, calculer la moyenne des deux valeurs du milieu.

5. Le mode

Définition : C'est la valeur ou la catégorie qui revient le plus souvent dans une distribution.

Cas particuliers :

  • Une distribution peut avoir un seul mode (unimodal), plusieurs modes (bimodal, multimodal) ou aucun mode si toutes les valeurs apparaissent le même nombre de fois.
  • C'est la seule mesure utilisable pour des données qualitatives (catégories).

6. Tableau comparatif des mesures

Mesure Avantages Inconvénients / Quand l'utiliser
Moyenne Utilise toutes les données. Influencée par les valeurs aberrantes. À utiliser si la distribution est symétrique.
Médiane Ignore les valeurs aberrantes. Ne tient pas compte de la valeur exacte de chaque donnée. À utiliser s'il y a des extrêmes.
Mode Fonctionne aussi pour les catégories. Peut ne pas exister ou ne pas être unique.

7. Technologies (Google Sheets / Excel)

Pour vérifier vos calculs rapidement avec la technologie :

  • Moyenne : =MOYENNE(plage)
  • Médiane : =MEDIANE(plage)
  • Mode : =MODE(plage)

9. Résumé final pour l'examen

  • Toujours classer les données en ordre croissant avant de chercher la médiane.
  • Vérifier s'il y a des valeurs aberrantes pour savoir s'il faut privilégier la médiane plutôt que la moyenne.
  • Bien se souvenir des formules de la moyenne arithmétique et de la moyenne pondérée.
